## Créer des SOPs

### Nouvelle SOP
```
Crée une SOP pour : [nom du processus]
Contexte : [décris le processus en quelques mots]
Outils utilisés : [outils]
Format attendu : Titre, Objectif, Prérequis, Étapes numérotées, Vérification finale
Niveau de détail : [débutant / intermédiaire — pour quelqu'un qui fait ça pour la première fois]
```

### Améliorer une SOP existante
```
Voici ma SOP actuelle pour [processus] :
[colle la SOP]

Améliore-la en :
1. Ajoutant les étapes manquantes
2. Clarifiant les étapes ambiguës
3. Ajoutant des points de vérification qualité
4. Identifiant les points de blocage courants
```

## Suivi des projets clients

### Update hebdomadaire interne
```
Voici le statut de mes projets actifs :
[colle la liste de tes clients et leur avancement]

Génère un résumé structuré avec :
- Ce qui est en retard (et pourquoi)
- Ce qui est dans les temps
- Les actions urgentes à faire aujourd'hui
- Ce à quoi me préparer cette semaine
```

### Email d'update client
```
Rédige un email d'avancement pour [nom du client].
Offre : [offre]
Avancement : [ce qui a été fait / ce qui reste]
Prochaine étape : [ce qu'on livre ou ce qu'on attend d'eux]
Ton : professionnel, rassurant, proactif
```

### Rapport mensuel
```
Crée un rapport mensuel pour [nom du client].
Période : [mois]
Travail effectué : [liste des livrables]
Résultats obtenus : [métriques si disponibles]
Plan du mois prochain : [à venir]
Format : Court, visuel (utilise des emojis ou sections claires), envoyable par email
```

## Onboarding client

### Email de bienvenue
```
Rédige un email de bienvenue pour un nouveau client.
Nom : [nom]
Offre achetée : [offre]
Prochaines étapes : [liste les 3 premières étapes du processus]
Ton : chaleureux, professionnel, organisé
```

### Checklist onboarding
```
Crée une checklist d'onboarding pour l'offre [offre].
Inclure :
- Ce qu'on a besoin du client (assets, accès, infos)
- Ce qu'on s'engage à livrer et quand
- Les outils de communication qu'on va utiliser
- Le processus de feedback et révisions
```
