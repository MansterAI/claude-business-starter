## Préparer un appel

### Avant un appel de découverte
```
Prépare-moi pour un appel découverte avec ce prospect :
Nom : [nom]
Secteur : [secteur]
Ce que je sais de lui : [notes]
Ce qu'il cherche : [si connu]

Donne-moi :
1. Les 5 questions à poser pour qualifier
2. Les points à clarifier sur mon offre
3. Les objections probables et comment les gérer
4. Comment positionner mon offre par rapport à ses besoins
```

### Après un appel (notes structurées)
```
Voici mes notes brutes d'un appel avec [nom] :
[colle tes notes]

Structure-les en :
- Situation actuelle du prospect
- Douleur principale identifiée
- Budget confirmé / estimé
- Timing
- Objections soulevées
- Prochaine étape convenue
- Mon évaluation : chaud / tiède / froid
```

## Emails de vente

### Suivi après un appel
```
Rédige un email de suivi après mon appel avec [nom du prospect].
Ce dont on a parlé : [résumé]
Offre proposée : [offre]
Prochaine étape : [ex. "je lui envoie la proposition", "il réfléchit"]
Ton : professionnel mais chaleureux
```

### Relance d'un prospect silencieux
```
Rédige un email de relance pour [nom] qui n'a pas répondu depuis [durée].
Dernier échange : [contexte]
Objectif : reprendre la conversation sans être pushy
Maximum 5 lignes.
```

### Proposition commerciale
```
Crée une proposition commerciale pour [nom du client].
Offre : [offre]
Contexte de sa situation : [ses douleurs, son objectif]
Prix : [prix]
Format : Court, orienté résultats, pas de jargon.
```

---

## Gérer les objections

### Réponse à une objection
```
Réponds à cette objection : "[objection exacte]"
Contexte : prospect [description] intéressé par [offre]
Ton : empathique, direct, sans pression
Format : 2-3 phrases max
```

### Préparer les objections probables
```
Mon prospect est [description de l'avatar].
Offre : [offre à [prix]]
Quelles sont les 5 objections les plus probables et comment y répondre ?
```

## Analyser le pipeline

### Revue pipeline hebdomadaire
```
Voici mon pipeline actuel :
[colle les données ou décris les prospects]

Analyse et dis-moi :
1. Quelles opportunités prioriser cette semaine ?
2. Quels leads relancer en urgence ?
3. Quels prospects sont probablement perdus ?
4. Une action concrète pour chaque opportunité chaude
```
