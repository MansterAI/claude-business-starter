# Agent Marketing — Prompts Réutilisables

<!-- ✅ Pré-rempli. Utilise ces prompts directement ou adapte-les. -->

---

## Créer du contenu

### Hook réseau social
```
Crée 5 hooks pour [Instagram/Facebook/LinkedIn/YouTube] sur le thème "[thème]".
Cible : [Avatar X — copie sa description depuis audience.md]
Format : courts, percutants, maximum 2 lignes.
Style : [curiosité / douleur / contre-intuition / chiffre / révélation]
```

### Caption complète
```
Écris une caption [Instagram/Facebook] pour ce visuel : [décris le visuel]
Offre mise en avant : [nom de l'offre]
Avatar ciblé : [Avatar X]
CTA : [ex. "Lien en bio", "Commente X", "DM-moi le mot Y"]
Ton : [selon voice-tone.md]
Longueur : [courte 50-80 mots / moyenne 100-150 mots / longue 200+ mots]
```

### Script vidéo court (Reel/TikTok)
```
Écris un script pour une vidéo de [30/60/90] secondes.
Sujet : [sujet]
Structure : Hook (5 sec) → Problème (10 sec) → Solution (20-40 sec) → CTA (5-10 sec)
Avatar : [Avatar X]
Offre : [offre à mentionner ou ne pas mentionner]
```

## Publicités

### Angle publicitaire
```
Génère 3 angles publicitaires différents pour l'offre "[offre]".
Avatar : [Avatar X]
Douleur principale : [douleur]
Format : Angle (1 phrase) + Accroche (1-2 phrases) + Corps (3-4 phrases) + CTA
```

### Texte d'annonce Meta Ads
```
Écris un texte d'annonce Facebook/Instagram pour :
Offre : [offre]
Avatar : [Avatar X]
Objectif : [notoriété / leads / ventes]
Format : Primary text (court, percutant) + Headline (5 mots max) + Description (1 ligne)
```

---

## Analyse

### Analyse de métriques
```
Voici les métriques de mes [posts/campagnes] de la semaine :
[colle tes données]

Analyse et réponds :
1. Qu'est-ce qui performe le mieux et pourquoi ?
2. Qu'est-ce qui sous-performe ?
3. 3 recommandations concrètes pour la semaine prochaine
```

### Audit contenu
```
Voici mes 5 derniers posts : [colle les textes ou décris-les]
Fais un audit rapide :
- Cohérence avec le positionnement ?
- Clarté du message ?
- Force des CTAs ?
- Ce que j'améliorerais en priorité
```

Contenu original : [colle le contenu]
